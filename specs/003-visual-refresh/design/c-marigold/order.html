Design notes

  • Status first: the hero card names the current status in its own colour and icon (Preparing = terracotta + chef hat), then “Expected by 8:25 pm” on an indigo-tint strip, a seven-step progress bar and the refresh time. When the status changes the card cross-fades its colour and label in 150 ms.
  • Map: drawn as a calm, stylised frame (sea, Sharavathi estuary, NH 66 in marigold with the bridge, side roads, paddy), with the custom kitchen pin (marigold, ink fork and spoon) and delivery pin (leaf green, house) and a dotted indigo route. The product keeps its real map tiles; this is the framing, pins and legend. If tiles fail, the same frame shows with pins and labels.
  • Call kitchen is the primary action, next to the kitchen's photo and landmark.
  • On this order's own page the Orders tab drops the status line (the order is on screen); the Cart tab is plain because the cart is empty.
  • Timeline: filled leaf nodes for done, a marigold node with a halo for now, outlined nodes with “Waiting” for later; each step has its own icon.
