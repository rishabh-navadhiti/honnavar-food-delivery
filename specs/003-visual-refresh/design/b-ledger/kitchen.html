Kitchen

The header is one compact block: photo, name, type and open-state badges, the delivery estimate and Call together; address and hours fold into a single expander row. Dishes are 96 px rows with a square photo, the veg mark before the name and a full-size Add or stepper on the right. The Cart tab carries the running total, so there is no in-page cart bar. The same template is rendered in English and Kannada; Kannada gets the same size and +3–6 px of leading.
