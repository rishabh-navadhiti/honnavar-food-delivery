Dispatch board

Admin moves to a top navigation so the board gets the full 1232 px: five 237 px columns, each with an icon, its count and a colour rule. Every card answers dispatch's questions without opening it: number, status and minutes in that status, kitchen, landmark, total, payment, and the agent (or an amber “Needs agent” with the assign control right on the card). The agent picker shows each agent's undelivered load on a second line instead of truncating it; Reassign (the arrows button) opens the same picker.
