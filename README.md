# Honnavar Food Delivery (POC)

A bilingual (Kannada / English) food delivery proof of concept localised to Honnavar, Uttara Kannada.
Four surfaces in one codebase: customer app, food partner app, delivery agent app, and an admin web panel.

Built with [Spec Kit](https://github.com/github/spec-kit). Specs live in `specs/`,
project principles in `.specify/memory/constitution.md`.

- Product requirements: `docs/prd/`
- What is real vs stand-in in the POC: `docs/fidelity-matrix.md`
